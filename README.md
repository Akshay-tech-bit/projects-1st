## 📝 Simple Todo List

A simple and interactive **Todo List Web Application** built using **HTML, CSS, and JavaScript**.

This project allows users to easily create and manage their daily tasks. Todo items are stored in the browser using **LocalStorage**, so the tasks remain available even after refreshing the page.

## 🚀 Features

* ➕ Add new todo items
* ⌨️ Add tasks by pressing the **Enter** key
* ✅ Mark tasks as completed using a checkbox
* ✏️ Edit tasks by **double-clicking** on them
* 🗑️ Delete todo items
* 💾 Save todos using **LocalStorage**
* 🔄 Automatically restore saved tasks after page refresh
* 🚫 Prevent empty tasks from being added

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and layout
* **JavaScript** — Application logic and DOM manipulation
* **LocalStorage** — Persistent storage of todo items

## ⚙️ How It Works

### 1. Add a Todo

Enter a task in the input field and click the **Add** button.

You can also press **Enter** to add the task.

### 2. Complete a Todo

Click the checkbox next to a task to mark it as completed.

Completed tasks are displayed with a **strike-through effect**.

### 3. Edit a Todo

Double-click the todo text to edit the task.

### 4. Delete a Todo

Click the **Delete** button to remove a task from the list.

### 5. LocalStorage

The application stores the todo data in the browser's LocalStorage. This means your tasks remain saved even when the page is refreshed or reopened.

## 💻 How to Run
